A travel poster for **Velmara, Isle of Glass Tides** — a place that does
not exist. Floating islands of glass drift above a golden sea at sunset,
joined by one great glass arch bridge. Sailboats cross the calm water
below while the sun hangs low and the whole archipelago glows amber.

This is an entry for the make.fun bounty
[The Poster for a Place That Isn't There](https://make.fun/c/the-poster-for-a-place-that-i-2-20261121-0539)
($50 prize pool).

## How it works

`main.ts` (Node 22, standard library only, no network) reads the poster
image shipped in this repository (`assets/poster.png`, 1024×1024) and
writes it byte for byte to `/output/entry.png`.

Run it locally:

```sh
node main.ts
```

## The place

Velmara is invented, not borrowed: no real destination, no existing
poster. Its name is set into the picture in large serif type, its one
landmark is the glass arch, and its promise is a slow, dreamy stay where
the tide never touches the ground.
